# Technical Design: Anchored Native Ignored Paths

## 1. Overview

In an Expo monorepo managed with Continuous Native Generation (CNG), native directories (`android/` and `ios/`) generated by `npx expo prebuild` must be ignored by version control. However, local custom native Expo modules stored in `apps/mobile/modules/<module-name>/android/` and `apps/mobile/modules/<module-name>/ios/` are checked-in source code and must never be ignored.

## 2. Root Cause Analysis

Commit `28f43cd` converted root `.gitignore` paths:

```diff
-# generated native folders
-/ios
-/android
+# generated native folders
+ios/
+android/
```

In gitignore specification:

- Patterns without a leading slash match anywhere in the file hierarchy (recursive).
- EAS CLI build creation invokes `Ignore.createForCopyingAsync` (using `ignore` npm package) to create project archives.
- The recursive pattern `android/` caused EAS to exclude all files inside `apps/mobile/modules/*/android/`.
- Autolinking relies on `build.gradle` being present inside module directories to identify active Android projects. With `build.gradle` omitted, the modules were silently skipped during Gradle project generation.

## 3. Architecture & Target State

```
Root .gitignore
├── /ios/                   -> Matches only root ios/
├── /android/               -> Matches only root android/
├── /apps/mobile/ios/       -> Matches only generated CNG ios folder for mobile app
└── /apps/mobile/android/   -> Matches only generated CNG android folder for mobile app

apps/mobile/modules/
├── meditation-session/
│   ├── android/            -> UNMATCHED (preserved in VCS and build archive)
│   │   ├── build.gradle
│   │   └── src/main/java/.../MeditationForegroundService.kt
│   └── ios/                -> UNMATCHED (preserved in VCS and build archive)
└── dnd-status/
    ├── android/            -> UNMATCHED (preserved in VCS and build archive)
    └── ios/                -> UNMATCHED (preserved in VCS and build archive)
```

## 4. Implementation Details

Modify root `.gitignore` lines 43-46:

```gitignore
# generated native folders
/ios/
/android/
/apps/mobile/ios/
/apps/mobile/android/
coverage/
```

## 5. Verification & Rollout

1. **Ignore evaluation check**: Verify that `apps/mobile/modules/*/android/` is not ignored and `apps/mobile/android/` is ignored using the `ignore` engine.
2. **Autolinking resolution**: Run `expo-modules-autolinking resolve -p android` from `apps/mobile` to confirm `meditation-session` and `dnd-status` are discovered.
3. **Continuous Integration**: Run `make check` to ensure monorepo tests, types, and lints pass.
